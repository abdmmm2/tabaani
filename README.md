# تابعني — تابعني للخدمات الذكية + الموقع التعريفي

مشروع عربي (RTL) كامل: **نظام إدارة خدمات مدرسية متعددة الأدوار** + **موقع تعريفي بهوية بصرية ذهبية**.
كل شيء ملفات ثابتة تعمل في المتصفح: بلا خادم، بلا تثبيت، بلا إنترنت، وبلا أي مكتبة خارجية (كل المكتبات مستضافة محليًا).

---

## التشغيل السريع

```bash
# 1) تابعني للمدارس  ← المقصود بهذا المستودع أساسًا
cd app && python3 -m http.server 8081
#    ثم افتح: http://localhost:8081

# 2) الموقع التعريفي
cd site && python3 -m http.server 8080
#    ثم افتح: http://localhost:8080
```

> **مهم:** شغّل عبر خادم محلي لا بفتح الملف مباشرة (`file://`)، لأن **بصمة الوجه** تحتاج الكاميرا
> ولا تعمل إلا على `https` أو `localhost`. باقي تابعني تعمل على `file://` أيضًا.

## بيانات الدخول (نموذج تجريبي)

**التهيئة الأولى:** عند أول تشغيل تُفتح شاشة **إنشاء حساب المشرف العام** — أنت من يُنشئ حسابك بنفسك، ولا توجد كلمة مرور مكتوبة في الكود.
اختر «بيانات عرض تجريبية» لتبدأ بمدرسة كاملة، أو «مدرسة حقيقية من الصفر» لتُنشئ بياناتك بنفسك.

> في وضع «بيانات عرض تجريبية» يوجد **خيار ظاهر** (مفعّل افتراضيًا): إضافة حساب المشرف العام التجريبي **`admin`**
> بالكلمة الموحّدة أدناه، لسهولة تجربة دور المشرف العام. **أوقفه إن كنت ستشارك تابعني مع أحد.**
> وفي «مدرسة حقيقية من الصفر» لا يوجد أي حساب جاهز — حسابك أنت هو المشرف العام.

**كلمة المرور الموحّدة للحسابات التجريبية: `Tabaani@2026`**

| الدور | اسم المستخدم | الدور | اسم المستخدم |
|---|---|---|---|
| مشرف تابعني *(بيانات العرض — بالخيار أعلاه)* | `admin` | معلم (٦ حسابات) | `teacher1` … `teacher6` |
| مدير المدرسة | `principal` | وكيل شؤون المعلمين | `tdeputy` |
| وكيل شؤون الطلاب | `deputy` | مسؤول ساعات التطوع | `volunteer` |
| موجّه التوجيه والإرشاد | `guidance` | مسؤول النشاط الطلابي | `activity` |
| مراقب الغياب | `monitor` | طالب (٤ حسابات) | `student1` … `student4` |
| **المحاسب المالي لتابعني** | `accountant` | **موظف الدعم الفني** | `support1` |

> شاشة الدخول فيها **إنشاء حساب جديد** و**استعادة كلمة المرور**. والأدوار الإدارية الجديدة تُرسل طلبًا يعتمده مدير المدرسة.
> ⚠️ كلمات المرور الموحّدة **للعرض فقط**؛ يجب استبدالها بمصادقة حقيقية (خادم + تشفير) قبل أي استخدام فعلي.
> 🔐 **حسابات الموظفين تطلب تحققًا بمرحلتين** (رمز على تلقرام)، وحساب `admin` وحسابات الطلاب لا تطلبه (انظر «التحقق بمرحلتين»).

## ما تعرفه تابعني

| الخدمة | التفصيل |
|---|---|
| المدرسة والحسابات | مناطق ومدن بقوائم انزلاقية → تأسيس مدرسة → إنشاء مديرها وحساباتها |
| المعلمون من نور | استيراد Excel/CSV، إسناد المواد بحسب المرحلة، اختيار الفصول والمواد بقوائم انزلاقية |
| تثبيت الوكيل | يثبّت إسناد المعلم فيظهر له في التحضير **فصوله فقط** |
| الطلاب | استيراد وإسكان في الفصول ونقل فردي/جماعي مع سجل نقل (بيد وكيل شؤون الطلاب) |
| جدول الحصص | ضبط الحصص وقاعدة الإغلاق، ورفع الجدول (Excel/CSV أو PDF) لإسناد الحصص تلقائيًا |
| التحضير | لكل حصة، مع منع الإغلاق قبل منتصف الحصة/نهايتها + تقارير فورية + رسائل تلقرام |
| المخالفات السلوكية | دورة كاملة: معلم → توجيه وإرشاد → وكيل (خصم درجة/لائحة) → إغلاق + تقرير مفصل |
| الاستئذان | طلب من التوجيه → منح من الوكيل (تابعني/جوال/تلقرام) → **تصريح خروج بباركود** وتاريخ هجري |
| التحقق بمرحلتين | **كلمة المرور ثم رمز من ٦ أرقام** يُرسل إلى **المحادثة الشخصية** للموظف على تلقرام — يُستهلك مرة واحدة وينتهي بعد مدة محدّدة، ويُقطع بعد عدد محاولات. يخضع له **كل الحسابات عدا الطلاب** — وهو **إلزامي افتراضيًا**، مع إمكان إيقافه أو جعله اختياريًا من الإعدادات |
| تلقرام خاص لكل معلم | كل مستخدم يربط **محادثة تلقرام شخصية (`chat_id`)** من «الرسائل الخاصة»، فتصله أذون الدخول والرسائل **عليه وحده** لا في مجموعة المدرسة (مع زر رسالة تجريبية) |
| إذن دخول الفصل | للطالب **المتأخر**: يصدره الوكيل أو التوجيه والإرشاد للمعلم، ويُكتب فيه **سبب التأخر** إلزاميًا — ويسلَّم **ورقيًا (بترويسة وباركود) + تلقرام + رسالة خاصة وإشعار في تابعني**، ويُتابَع اطّلاع المعلم وإقراره باستلام الطالب |
| المناوبة | أماكن + توزيع آلي عادل + فترات (الفسحة · بين الحصص · نهاية اليوم/خروج الطلاب) + تذكير تلقرام قبلها بيوم + **لافتة يوم المناوبة** |
| إيقاف/تفعيل حسابات الطلاب | **مشرف تابعني** من لوحته مباشرة: زر **«إيقاف كل الطلاب»** لكل المنصّة، وزر **«إيقاف طلاب هذه المدرسة»** لمدرسة واحدة (مع قائمة اختيار المدارس) — كلاهما ضغطة + تأكيد، والزر يتحوّل للتفعيل، مع إحصاء لكل مدرسة وسجل تدقيق وإشعار |
| الباقات والاشتراكات | **باقتان لكل مدرسة**: «تابعني كلاسيك» (كل الوحدات بلا تلقرام) و«تابعني برو» (كل الخدمات + تلقرام) — مع رسم تأسيس وتهيئة مرة واحدة واشتراك سنوي، وتاريخ سريان لكل مدرسة |
| إيقاف/تفعيل دخول مدرسة | **زر واحد مباشر على لوحة المشرف العام** «إيقاف دخول المدرسة» ⇄ «تفعيل دخول المدرسة» بضغطة + تأكيد يشرح الأثر — ومعه «تحديد السبب والملاحظة» (عدم سداد الرسوم · مشكلة تشغيلية · أخرى) وسجل تدقيق وإشعار |
| المالية والفواتير | تحويل بنكي ← رفع **سند التحويل مختومًا بختم المدرسة** ← اعتماد ← **فاتورة إلكترونية** برقم متسلسل (`TBN-YYYY-NNNN`) وترويسة تابعني وشعارها والتاريخ والوقت، **مختومة بختم «تابعني للخدمات الذكية»**، وبها بيانات المدرسة ونوع الباقة — و**تفعيل الباقة آليًا** عند الاعتماد |
| المصروفات | تسجيل مصروفات تابعني: **صيانة تابعني · السيرفرات والاستضافة · التشغيل · الدومين والشهادات · الدعم الفني · أخرى** — بإجماليات لكل فئة وسجل تدقيق |
| التقارير المالية | **يومي · أسبوعي · شهري · ربع سنوي (٣ أشهر) · نصف سنوي (٦ أشهر) · سنوي**: إيرادات التأسيس والاشتراكات · المصروفات · **الصافي** · تحصيل متوقّع · طلبات معلّقة — مع طباعة بترويسة تابعني والختم والتوقيعات |
| المحاسب المالي لتابعني | **دور مستقل** (`accountant`): الفواتير والسدادات والمصروفات والتقارير المالية وبيانات التحويل — يفتح له **المشرف العام** حسابًا من «إدارة المستخدمين» |
| الدعم الفني (البوت) | بوت **«فارس الحربي»** (الشفت الأول ٨ص–٨م) و**«هند المطيري»** (الشفت الثاني ٨م–٨ص) — **صورتاهما يسار الاسم**، ويتحدّثان **بلهجة سعودية**، ويستقبل البوت **صورة المشكلة** ويفرزها ويفتح **تذكرة متابعة** |
| نظام التذاكر | كل تذكرة برقم (`TKT-YYYY-NNNN`) تصل **قسم الدعم الفني** و**المشرف العام** مع الصور المرفقة، ويُرد عليها من وحدة «الدعم الفني» مع تحويل/إغلاق وتغيير الحالة |
| بصمة الوجه | تسجيل بصمة المعلم + **طلب تمرير الوجه عند الدخول** + تسجيل حضور الحصة بالوجه |
| التقارير | يومية/أسبوعية/شهرية/نهاية الفصل + رسوم بيانية + طباعة PDF **بترويسة رسمية وباركود** |
| ترويسة التقارير | يضبطها **مدير المدرسة**: البسملة · المملكة العربية السعودية · وزارة التعليم · **إدارة التعليم (قائمة منسدلة بـ16 إدارة)** · اسم المدرسة (في المنتصف) → شعار الوزارة وشعار المدرسة → **تاريخ الإصدار والباركود** → اسم التقرير بخط كبير → وفي آخر التقرير **معد التقرير والتاريخ والوقت** |
| التحليلات | الأكثر غيابًا/تأخرًا/حضورًا · **نسب الحرمان لكل مادة يضبطها الوكيل** · تفعيل المعلمين لتابعني |
| خدمات أخرى | ساعات التطوع · النشاط الطلابي · مراقبة الغياب · مركز تقارير بالباركود |
| الحسابات | **تسجيل حساب جديد** (الطالب يُفعَّل فورًا والإداري بانتظار اعتماد المدير) · **استعادة كلمة المرور** برمز تحقّق · تغيير كلمة المرور من الحساب |
| إدارة الحسابات | **إيقاف/تفعيل حسابات الطلاب كلهم بضغطة واحدة** (لكل المدرسة أو لصف محدّد) أو فرديًا، وحسابات الموظفين، وطلبات الاعتماد |
| إدارة المستخدمين (المشرف العام) | شاشة كاملة: **إضافة مستخدم** · **تعطيل/تفعيل** · **تغيير الدور** · إعادة تعيين كلمة المرور · توليد كلمات مرور مختلفة لكل حساب عند التسليم (كشف CSV + كشف مطبوع بالتوقيعات) |
| الإعلان الافتتاحي | نافذة تحكم كاملة: تفعيل/إيقاف · إضافة إعلانات · تدويرها · تكرار العرض · الإغلاق التلقائي · تصدير `promo-config.js` |
| جنس المدرسة | عند تسجيل المدرسة تحدّد **طلاب أو طالبات**، فتتغيّر كل المسمّيات والنصوص تلقائيًا (وكيل/وكيلة · معلم/معلمة · مدير/مديرة · الطلاب/الطالبات) |

## النسخة الاحتياطية المجدولة

- **الموعد الافتراضي: الخميس ٤ مساءً** (قابل للتغيير: أي يوم · أي ساعة · أو تعطيل).
- يظهر **شريط تذكير** أعلى المنصة للمشرف العام وقائد المدرسة عند أول فتح بعد الموعد، فيه:
  **تنزيل النسخة الآن** (تنزيل فوري + تسجيل الوقت) · **تأجيل أسبوعًا** · إخفاء — مع **إشعار نظام** إن كان مسموحًا والمنصة مفتوحة.
- المتصفح لا يشغّل تابعني وهي مغلقة (بلا خادم) — لذلك التذكير يظهر **عند أول فتح بعد الموعد**، وهو مصمّم ليُنجَز بضغطة واحدة.
- الإعداد والتاريخ في: **بيانات تابعني ← موعد النسخة الاحتياطية** (آخر نسخة · الموعد الحالي · حالة التذكير).

### حفظ النسخة الاحتياطية في Google Drive

**أسهل طريقة (بلا أي إعداد داخل المنصة):**

| جهازك | الخطوات |
|---|---|
**كمبيوتر (كروم)** | ثبّت **Google Drive for Desktop** ← الإعدادات في كروم ← **التنزيلات** ← **مكان الحفظ = مجلد Google Drive** — بعدها **كل نسخة تذهب إلى الدرايف وحدها** وتُزامن سحابيًا |
**كمبيوتر (بدون تثبيت Drive)** | كروم ← التنزيلات ← **«اسأل عن مكان حفظ كل ملف»** ← اختر مجلد الدرايف عند كل نسخة (نقرتان) |
**آيباد / آيفون (سفاري)** | الإعدادات ← **سفاري** ← التنزيلات ← **«iCloud Drive»** (أو على الجهاز) ← ثم انقل الملف إلى Google Drive من تطبيق **«الملفات»** |

### الحفظ السحابي داخل تابعني (مبنيّ — Google Apps Script)

بلا خادم وبلا مكتبات خارجية: **نقطة الرفع = تطبيق Google Apps Script** ينشره المستخدم في حسابه مرة واحدة،
فيحفظ الملف في مجلد **«تابعني — النسخ الاحتياطية»** داخل درايفه (يحتفظ بآخر **١٢** نسخة ويحذف الأقدم).

**الإعداد (خمس دقائق، من `بيانات تابعني ← الحفظ السحابي في Google Drive ← إعداد الربط`):**
1. `script.google.com` ← مشروع جديد ← الصق الكود (زر «انسخ الكود»).
2. **نشر ← نشر جديد ← تطبيق ويب** · «تنفيذ باسمي» · «أي شخص» ← نشر ← الموافقة على الأذونات.
3. انسخ رابط `/exec` ← الصقه في تابعني ← **«احفظ واختبر»** (يُرسل ملف اختبار ويتأكد أن الردّ سليم).

**السلوك:**
- بعد الربط: كل نسخة (من التذكير الأسبوعي أو الزر) **تُنزَّل محليًا وترفع تلقائيًا** إلى درايف.
- **بلا إنترنت:** تُحفظ النسخة في **طابور** وتُرفع تلقائيًا عند عودة الاتصال.
- الرفع بطلب `POST` بسيط (`text/plain`) بلا preflight؛ وإن تعذّر قراءة الردّ نُعيد المحاولة بـ `no-cors`
  ونُبلغ «أُرسل بلا تحقّق»، أما أخطاء HTTP الصريحة فتُسجَّل كفشل واضح (لا نجاح كاذب).
- سجل آخر ٣٠ عملية رفع داخل اللوحة + رابط المجلد + عدد النسخ المرفوعة + زر الفصل.
- الصلاحية: الرابط سرّي ويكتب فقط في مجلد النسخ (لا يقرأ شيئًا من درايفك).

## الصفحة الرئيسية والموقع العام

- **الصفحة الرئيسية = رابط تابعني** (`app/`) — واجهة الموقع العامة **بصفحات منفصلة** (لا صفحة واحدة طويلة):
  الرئيسية · مميزاتنا · المدارس الذكية · حول مدرستك · الأسعار والباقات · عن تابعني · الدعم الفني · تواصل معنا.
  التنقّل من الترويسة (٦ روابط) أو من **القائمة المنسدلة** (ثلاثة خطوط).
- **الترويسة ثابتة**: اللوغو والاسم **يمينًا**، وأيقونة الدخول وزر «تسجيل الدخول» **يسارًا** — واللوغو يبقى ظاهرًا أثناء التمرير.
- **أيقونة الدخول** تفتح نافذة **بيانات الدخول** (مستخدم + كلمة مرور) مع رابطي الاستعادة والتسجيل؛
  وإن كان الجهاز غير مُهيّأ تفتح «تهيئة تابعني» مع شريط تنبيه أعلى الصفحة.
- **الإعلان** يظهر في الصفحة الرئيسية فقط: زر إغلاق (×) · **إغلاق تلقائي بعد مدة** · تكرار العرض
  (كل فتح · مرة لكل جلسة · مرة لكل زائر) · **تاريخ انتهاء** للإعلان · وحذف الإعلان نفسه —
  كل ذلك من **«الإعلان الافتتاحي»** في لوحة المشرف العام.
- **الهوية البصرية**: أبيض + **أخضر زمردي** (`#0E5F4C`) + **ذهبي محدود** (`#C69A3E`) — بلا خلفيات داكنة.
- **الصفحة القديمة** (`index.html` الجذر و`site/index.html`) صارت **لوغو مهيبًا** يحوّل تلقائيًا إلى تابعني.

## المالية: سند التحويل والفاتورة الإلكترونية

**دورة السداد كاملة (تحويل بنكي — بلا بوابة دفع):**

1. **مدير المدرسة** ← «الاشتراك والدفع»: يرى بيانات الحساب البنكي، ويختار المطلوب (اشتراك سنوي أو رسم التأسيس) والباقة وعدد السنوات — والمبلغ يُحسب تلقائيًا.
2. يحوّل المبلغ بنكيًا، ثم **يرفع صورة سند التحويل مختومة بختم المدرسة** (تُضغط تلقائيًا إلى JPEG ≤1100px فلا تثقل المتصفح) — ويمكنه رفع **صورة ختم المدرسة** منفصلة.
3. الطلب يصل **المشرف العام + المحاسب المالي** كإشعار، مع صورة السند للمراجعة.
4. **الاعتماد** («اعتماد وتفعيل») → يُسجَّل السداد وتُمدّد السنة **وتُفعَّل الباقة آليًا** (ويُرفع إيقاف الرسوم إن وُجد) → **تُصدر الفاتورة الإلكترونية**.

**الفاتورة** (طباعة أو حفظ PDF مباشرة من نافذة الفاتورة):

| العنصر | التفصيل |
|---|---|
| الرقم | متسلسل بالسنة: `TBN-2026-0001` |
| الترويسة | شعار تابعني + **«تابعني للخدمات الذكية»** + «تابعني للخدمات الذكية · tabaani.sa» |
| البيانات | **التاريخ (هجري + ميلادي) والوقت** · اسم المدرسة والمدينة ورمزها · **نوع الباقة المطلوبة** · البند والكمية والسعر والإجمالي |

## الدعم الفني: بوت بشفتين ونظام تذاكر

- **زر عائم** «الدعم الفني» أسفل يسار الشاشة في كل الأدوار — يعرض **صورة الموظف على يسار اسمه** ومن على الشفت الآن.
- **الشفتان**: `فارس الحربي` ٨ صباحًا – ٨ مساءً · `هند المطيري` ٨ مساءً – ٨ صباحًا (يُحسب من ساعة الجهاز).
- **اللغة**: لهجة سعودية ١٠٠٪ («هلا والله ومسهلا» · «أبشر بسعدك» · «ما يمديك…»).
- **قاعدة معرفة** بـ12 موضوعًا: التحضير · الدخول وكلمة المرور · الرمز بمرحلتين · تلقرام · التقارير والطباعة · الطلاب والاستيراد · المخالفات · الاستئذان والخروج · الاشتراك والفاتورة · التثبيت والإنترنت · الكاميرا وبصمة الوجه · النسخ الاحتياطي.
- **الصور**: يقبل لقطة الشاشة، يضغطها، ويعرض **فرزًا أوّليًا صريحًا** (النوع والأبعاد والحجم) ويرفقها بالتذكرة.
- **التذاكر**: «افتح تذكرة متابعة» → رقم `TKT-2026-0001` يصل **قسم الدعم** و**المشرف العام**، ويُتابع من وحدة «الدعم الفني» (رد · قيد المعالجة · بانتظار المستخدم · تحويل · إغلاق) — والرد يصل صاحب التذكرة ومدير مدرسته.

> **صراحة**: «تحليل الصورة» هنا **فرز أوّلي** (نوع/أبعاد/حجم + فهم نص الاستفسار). الفهم البصري الحقيقي لمحتوى الصورة يحتاج نموذج رؤية وخادمًا — جاهز للإضافة لاحقًا.

## الباقات والرسوم (تابعني كلاسيك · تابعني برو)

نموذج التسعير: **باقة واحدة للمدرسة كلها** — بلا احتساب لكل طالب، وبلا حدّ لعدد الحسابات.

| البند | السعر | ما يشمل |
|---|---|---|
| رسم التأسيس والتهيئة | **1000 ر.س** — مرة واحدة | تهيئة تابعني للمدرسة: الحسابات والأدوار · الفصول والطلاب · بيانات السنة الدراسية · تدريب الفريق ودليل تشغيل |
| **تابعني كلاسيك** — سنويًا | **1000 ر.س** | كل الوحدات (26 وحدة · 13 دورًا · التقارير الرسمية بباركود تحقّق · يعمل بلا إنترنت) — **بلا تلقرام** |
| **تابعني برو** — سنويًا | **1500 ر.س** | كل ما في «كلاسيك» + تلقرام: الإشعارات الفورية · الرسائل وأذون الفصل على الجوال · **التحقق بمرحلتين** · محادثة خاصة لكل مستخدم · بوت مستقل لكل مدرسة |

> الرسوم قابلة للتعديل من «بيانات تابعني ← الباقات والرسوم» (لأن الإحصاء والتحصيل المتوقّع يُحسبان منها).

**كيف تعمل الباقة داخل تابعني:**
- تُحدَّد **لكل مدرسة** (`school.plan`)، وتظهر كشارة في الشريط الجانبي وفي بطاقة «الباقة والاشتراك» في لوحة قائد المدرسة.
- **حجب تلقائي لخدمات تلقرام في «كلاسيك»:**
  - وحدة «سجل تلقرام» لا تظهر في القائمة الجانبية، وزر سجل تلقرام في الشريط العلوي يُخفى.
  - إرسال تلقرام مرفوض **برسالة صريحة** («غير مشمول في باقة تابعني كلاسيك») — لا فشل صامت، ولو ناداه أي كود داخلي.
  - حقول «محادثة تلقرام الشخصية» في نماذج المستخدمين والموظفين تظهر **معطَّلة** مع تنويه الترقية.
  - **التحقق بمرحلتين لا ينطبق في الكلاسيك** (الرمز يُرسل عبر تلقرام أصلًا) — فلا يُحبس أحد بسبب رمز لا يمكن أن يصله.
  - «الرسائل الخاصة» تبقى تعمل داخل تابعني، مع تنويه أن الربط على تلقرام في «برو».
- **الترقية/التخفيض** من نافذة «الباقة والاشتراك» بضغطة — والتغيير **مُقيَّد في سجل التدقيق** ومُرسل لإدارة المدرسة.

**الإيقاف — بيد المشرف العام وحده:**

| السبب | الأثر | كيف يُرفع |
|---|---|---|
| **عدم سداد الرسوم السنوية** | إيقاف **دخول المدرسة كلها** (المدير · الوكلاء · المعلمون · الطلاب) برسالة تشرح السبب | **تلقائيًا** عند تسجيل السداد · أو يدويًا «رفع الإيقاف» |
| **مشكلة تشغيلية** | نفس الأثر، برسالة مختلفة | يدويًا بقرار إدارة تابعني (**السداد وحده لا يرفعه**) |
| — | **حساب المشرف العام لا يُحجب أبدًا** (بوتقة أمان: وإلا قُفلت تابعني على صاحبها) | — |

**أين تُدار؟**
1. **لوحة المشرف العام** ← بطاقة «الباقة والاشتراك — هذه المدرسة»: **زر واحد مباشر «إيقاف دخول المدرسة» ⇄ «تفعيل دخول المدرسة»** (ضغطة + تأكيد) · تسجيل السداد (+سنة) · تحديد السبب والملاحظة · الباقة والتفاصيل — مع تنبيه «مدارس موقوفة» أسفل اللوحة وزر تفعيل لكل مدرسة فيه.
2. **المناطق والمدن والمدارس** ← عمودا «الباقة» و«الاشتراك» لكل مدرسة + زر «إدارة» لنافذة الباقة، ويُطبَعان في تقرير المدارس.
3. **بيانات تابعني ← الباقات والرسوم**: تعديل الرسوم الثلاثة + إحصاء (برو · كلاسيك · الموقوفة · التحصيل السنوي المتوقّع) وجدول إدارة لكل مدرسة.
4. **شاشة التهيئة الأولى** ← تحدّد الباقة الافتراضية ورسم التأسيس للمدارس التي تُضاف لاحقًا.

## التحقق بمرحلتين عند الدخول

كلمة المرور وحدها لا تكفي لحسابات الموظفين، فالمسار صار مرحلتين:

```
اسم المستخدم + كلمة المرور  →  رمز من ٦ أرقام على محادثة الموظف الشخصية في تلقرام  →  الدخول
```

| الجانب | التفصيل |
|---|---|
| على مَن يُطبَّق | **كل الحسابات عدا الطلاب** — معلم · مدير · وكيل · توجيه · أي موظف — وهو **إلزامي افتراضيًا** |
| من لم يربط بعد | **يُمنع من الدخول** (لأن الإلزام مفعّل افتراضيًا) برسالة تشرح أن مدير المدرسة يجب أن يربط محادثته — ويمكن إيقاف الإلزام من الإعدادات فيدخل بكلمة المرور وحدها |
| المشرف العام | **مستثنى من المنع دائمًا** (بوتقة أمان) حتى لا تُقفل تابعني على صاحبها — وإن ربط محادثة شخصية خضع للرمز مثل غيره |
| الرسالة | تُرسل إلى **محادثته الشخصية** لا إلى مجموعة المدرسة، وتُقيَّد في «سجل تلقرام» موسومة **«خاصة»** |
| الأمان | صلاحية الزمن (٥ دقائق افتراضيًا) · أقصى عدد محاولات (٥) · **يُستهلك مرة واحدة** · يُلغى عند الخروج · الرمز لا يخصّ غير صاحبه |
| الإعدادات | «سجل تلقرام ← التحقق بمرحلتين»: تشغيل/إيقاف · إلزام الجميع (**مفعّل افتراضيًا**) · مدة الرمز · عدد المحاولات — مع عدد الموظفين المرتبطين وبلا محادثة وأسماؤهم |
| بيانات العرض | حسابات الموظفين التجريبية مربوطة بمحادثات تجريبية حتى يظهر المسار كاملًا — تُستبدل بالمعرّفات الحقيقية عند التسليم |
| ربط المحادثة | الموظف نفسه من «الرسائل الخاصة ← ربط تلقرام»، أو مدير المدرسة من «الموظفون والحسابات»، أو المشرف من «إدارة المستخدمين» |
| في وضع المحاكاة | إن لم يُفعَّل الإرسال الفعلي إلى تلقرام، يظهر الرمز على الشاشة كـ«رمز معاينة» لتجربة المسار — وبعد ربط البوت يُرسل للجوال وحده ولا يظهر على الشاشة |

> ⚠️ **ترتيب التهيئة**: اربط محادثة **مدير المدرسة** أولًا ثم بقية الموظفين — وإلا منع التحققُ الدخولَ على من لم يربط. ولتجربة تابعني بحسابات بلا محادثات مربوطة: «سجل تلقرام ← التحقق بمرحلتين ← إيقاف».

## النشر على GitHub Pages

1. أنشئ مستودعًا فارغًا على GitHub ثم ارفع الملفات:
   ```bash
   git init && git add . && git commit -m "تابعني — الإصدار الأول"
   git branch -M main
   git remote add origin https://github.com/<حسابك>/<المستودع>.git
   git push -u origin main
   ```
2. من المستودع: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`** ثم Save.
3. بعد دقيقة سيكون:
   - الصفحة الرئيسية: `https://<حسابك>.github.io/<المستودع>/`
   - تابعني: `https://<حسابك>.github.io/<المستودع>/app/`
   - الموقع التعريفي: `https://<حسابك>.github.io/<المستودع>/site/`
4. **GitHub Pages يعمل بـ https** — لذا تعمل الكاميرا وبصمة الوجه تلقائيًا بلا أي إعداد.

## الإعلان الافتتاحي (نافذة تحكم كاملة)

الإعلان الذي يظهر عند فتح الموقع **يُدار من لوحة تحكم** لمشرف تابعني: **تابعني ← «الإعلان الافتتاحي»**.

| الإمكانية | التفصيل |
|---|---|
| تفعيل/إيقاف | زر واحد يوقف الإعلان تمامًا أو يفعّله |
| إضافة إعلان آخر | زر «إضافة إعلان جديد»: عنوان + صورة (رفع من الجهاز تُصغَّر تلقائيًا إلى 1080px، أو مسار صورة داخل الموقع) + رابط «اعرف أكثر» اختياري |
| أكثر من إعلان | بطاقات لكل إعلان مع «اجعله النشط» / تعديل / حذف، وعرض **النشط فقط** أو **تدوير كل الإعلانات** بالتناوب |
| تكرار العرض | مرة كل جلسة · كل فتح · مرة واحدة لكل زائر |
| إغلاق تلقائي | بعد عدد ثوانٍ (مع شريط تقدّم) أو يدوي فقط |
| معاينة | يرى الإعلان بنفس شكل ظهوره للزائر |
| نشر للزوار | زر «تنزيل promo-config.js» → يوضع في `site/assets/data/promo-config.js` ثم يُعاد نشر الموقع |

> التعديل يسري **فورًا على نفس المتصفح** عند وجود الموقع وتابعني على نطاق واحد (عبر مفتاح `localStorage` مشترك)، أما ظهوره **لجميع الزوار** فعبر ملف `promo-config.js` المصدَّر. الإعداد نفسه قابل للتصدير والنسخ من اللوحة.

## تسليم الحسابات (كلمات مرور مختلفة لكل حساب)

من لوحة **مشرف تابعني ← «إدارة المستخدمين»**:

1. **«توليد لكلم الحسابات»** (أو الموظفون فقط / الطلاب فقط) — يولّد كلمة مرور عشوائية قوية **مختلفة لكل حساب** (`Tbn@…` بحرف ورقم ورمز).
2. يظهر **كشف كلمات المرور** مباشرة: **تنزيل CSV** أو **طباعة كشف رسمي بترويسة المدرسة والتوقيعات**.
3. كل من وُلّدت كلمته يُلزَم بتغييرها: عند أول دخول تظهر له نافذة **«عيّن كلمة مرور جديدة»**.
4. الكلمة الموحّدة `Tabaani@2026` تصبح غير صالحة للحسابات التي وُلّدت لها كلمات جديدة (مُختبر).

> تنبيه صريح: في هذا النموذج تُخزَّن كلمات المرور داخل المتصفح (localStorage) **بلا تشفير** وفيها نصوص ظاهرة في الكشف. في الإنتاج: تشفير (hash) على الخادم + تحقق ثنائي + سجل تدقيق.

الفحص المطلوب: الدخول بكل دور، ثم التحقق من: نجاح الدخول · القائمة الجانبية = وحداته فقط · محاولة فتح وحدة محظورة عبر الرابط تُعاد إلى لوحته · صفر أخطاء JS.

```
✓ مشرف تابعني (7) · مدير المدرسة (14) · وكيل شؤون الطلاب (16) · وكيل شؤون المعلمين (5)
✓ موجّه التوجيه والإرشاد (9) · مسؤول ساعات التطوع (5) · مسؤول النشاط الطلابي (5)
✓ مراقب الغياب (3) · حارس البوابة (3) · معلم (9) · طالب (6)
✓ كل الأدوار: دخول سليم · صلاحيات معزولة · ولا تسرّب في العناوين
```

الأرقام أعلاه **مفحوصة آليًا** بـ`node tools/roles-e2e.js` (انظر «الأدوات» أدناه)، ولا تُحدَّث يدويًا إلا عمدًا.

## إذن دخول الفصل (الطالب المتأخر)

مكمّل لتصريح الخروج: إذا **تأخّر طالب** عن الحصة، يُصدر له **وكيل شؤون الطلاب** أو **موجّه التوجيه والإرشاد**
«إذن دخول فصل» مُرقّمًا (`EN-YYYY-NNNN`) — والوحدة في القائمة الجانبية باسم **إذن دخول الفصل**.

| الجانب | التفصيل |
|---|---|
| المُصدِر | وكيل شؤون الطلاب · موجّه التوجيه والإرشاد (كلاهما يُصدر مباشرة) |
| المستلم | **معلم الحصة** — يُختار تلقائيًا من معلمي فصل الطالب (مميّزين بـ★) مع إمكانية اختيار غيره |
| الحقل الإلزامي | **سبب تأخّر الطالب** (+ المادة · الحصة · وقت الوصول · مدة التأخر · ملاحظة اختيارية) |
| التسليم الورقي | زر **«طباعة الإذن (ورقي)»**: ترويسة المدرسة الرسمية + باركود تحقّق + توقيعات (المعلم المستلم · الجهة المُصدِرة) |
| التسليم بتلقرام | رسالة فورية موجَّهة **لمعلم الحصة باسمه** (تُسجَّل في «سجل تلقرام»). وإن ربط المعلم **محادثة شخصية** فتُرسل إليه وحده بدل مجموعة المدرسة |
| التسليم في تابعني | **رسالة خاصة** في بريد المعلم (`الرسائل الخاصة`) + **إشعار** باسمه في جرس التنبيهات |
| المتابعة | مسار الحالة: **أُصدر** ← **اطّلع عليه المعلم** ← **أقرّ المعلم باستلام الطالب**، ويصل الإقرار للجهة المُصدِرة. والإذن يظهر أيضًا لمدير المدرسة للاطلاع |
| الأثر | قيد في سجل التدقيق + تقرير مسجّل في «مركز التقارير» بنوع **إذن دخول فصل** |

> قوالب أسباب جاهزة (طابور صباحي · مواصلات · مراجعة طبية · ظرف عائلي · الحصة الأولى) لتسريع عمل الوكيل، مع إمكانية كتابة السبب بحرية.
>
> **ربط التلقرام الخاص:** يضبطه المعلم بنفسه من «الرسائل الخاصة ← ربط تلقرام»، أو مدير المدرسة من «الموظفون والحسابات»، أو مشرف تابعني من «إدارة المستخدمين». وبلا ربط تصل التنبيهات إلى مجموعة المدرسة كما كان.

## النافذة الافتتاحية (عرض «مجانًا ولفترة محدودة»)

عند فتح الموقع تظهر صورة العرض في نافذة منبثقة فوق الواجهة (`site/assets/js/splash.js`):

- تُغلق بزر **إغلاق** أو النقر خارجها أو **Esc**، وتُظهر **مرة واحدة في كل جلسة تصفّح** (لا تزعج الزائر في التنقّل بين الصفحات).
- الصورة بصيغتين: `promo-offer.webp` (113 ك.ب) و`promo-offer.jpg` (190 ك.ب) مع `<picture>` — بلا أي مكتبة خارجية.
- تحكّم سريع عبر الرابط: `?splash=1` لإظهارها دائمًا (للمعاينة) و`?splash=0` لمنعها.
- لا تظهر إن فشل تحميل الصورة، وتحترم `prefers-reduced-motion`.
- تغيير الصورة: استبدل `site/assets/img/promo-offer.jpg|webp`. ولإظهارها في أي صفحة: أضف `<script src="assets/js/splash.js" defer></script>` قبل `</body>`.

### قواعد إلزامية لأي تعديل
1. عربي RTL أولًا · بلا أي مكتبة خارجية (كل شيء محلي) · الذهبي دائمًا بنص داكن.
2. كل وحدة: `App.register({id,label,icon,roles,render})` في `app/assets/js/modules/`.
3. **أي تعديل للملفات يلزمه رفع رقم `CACHE` في `app/sw.js`** (وأرقام الإصدار في `app/index.html` وREADME) وإلا بقيت الأجهزة على نسخة قديمة.
4. قبل التسليم: `bash tools/matrix.sh` — ولا تُسلّم إن كان أي فحص فاشلًا.

## الأدوات — فحوص ما قبل التسليم

كلها **بلا أي مكتبة خارجية**: Node ‏(٢٢+) + Chrome/Chromium فقط. لا `npm install`.
إن لم يكن المتصفح في موضع معروف: `CHROME_BIN=/path/to/chrome bash tools/matrix.sh`.

| الأداة | ما تفحصه |
|---|---|
| `tools/matrix.sh` | **المنظّم**: يشغّل المراحل الثلاث ويطبع ملخصًا، ويكون رمز الخروج ≠ ٠ عند أي فشل |
| `tools/static-checks.js` | سلامة صياغة كل JS · صحة JSON · **كل ملف في `sw.js` موجود فعلًا** · موارد الصفحات موجودة محليًا **وبلا أي رابط خارجي** · **كل صور الأدلة والمعرض موجودة** · **تطابق رقم الإصدار** (`sw.js` ⇄ `index.html` ⇄ README) |
| `tools/roles-e2e.js` | يدخل بكل دور من شاشة الدخول الحقيقية: نجاح الدخول · القائمة الجانبية = وحداته فقط · العدد مطابق للجدول المتوقّع · الوحدة المحظورة تُعيده للوحته · كل وحدة تُرسم بلا خطأ · **صفر أخطاء JS** |
| `tools/mobile-check.js` | بمقاس جوال ٣٩٠×٨٤٤ ولمس: **لا تجاوز أفقي** في أي شاشة · زر القائمة وفتح/إغلاق الدرج · شريط الإجراءات لا يتجاوز · أهداف اللمس ≥ ٤٠ بكسل · صفر أخطاء JS |
| `tools/build-guides.js` | يولّد الأدلة الثلاثة **PDF** (Chrome بخطوط مضمّنة) و**Word** (LibreOffice بصور مدمجة مصغّرة) من صفحات HTML، ويتحقّق من عدد الصفحات واتجاه النص |
| `tools/browser.js` | مساعد مشترك: خادم ملفات + تشغيل المتصفح + اتصال CDP (يستخدمه الفحصان وتوليد الأدلة) |
