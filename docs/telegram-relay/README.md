# ربط بوت تلقرام — منصة تابعني

هذا الدليل يشرح ربط الإرسال الحقيقي إلى تلقرام. رتّبه في خمس دقائق.

---

## ١) أنشئ البوت (مرة واحدة)

1. افتح تلقرام وابحث عن **@BotFather**.
2. أرسل: `/newbot`
3. اختر **اسمًا** للبوت (يظهر للمستخدمين) ثم **معرّفًا** ينتهي بـ `bot`
   مثال: `TabaaaniSultanBot`
4. انسخ **الرمز (Token)** الذي يعطيك إياه — يشبه:
   `1234567890:AAH4xK9pQr7…`

## ٢) أنشئ مجموعة المدرسة

1. أنشئ مجموعة جديدة باسم المدرسة (مثال: «قيادة ثانوية الأمير سلطان»).
2. أضف البوت عضوًا في المجموعة.
3. اجعل البوت **مشرفًا** (Admin) حتى يستطيع الإرسال بلا قيود.
4. لمعرفة **معرّف المجموعة (chat id)**: أضف **@userinfobot** إلى المجموعة،
   أو أرسل رسالة في المجموعة ثم افتح:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   وابحث عن `"chat":{"id":-100…}`.

> معرّف المجموعة يبدأ بعلامة ناقص، مثل: `-1001234567890`

## ٣) اختر وضع الإرسال

| الوضع | الوصف | الأمان | متى تستخدمه |
|---|---|---|---|
| **وسيط (موصى به)** | خدمة صغيرة تحمل الرمز خارج المتصفح | الرمز لا يظهر في المنصة | الاستخدام الحقيقي |
| **مباشر** | الرمز داخل المنصة من المتصفح | الرمز مكشوف لأي فتح للمنصة | تجربة سريعة فقط |
| **محاكاة** | لا إرسال، فقط سجل | — | العرض التجريبي |

### الوسيط — الطريقة المجانية
اختر إحدى الطريقتين في مجلد `telegram-relay`:

- **`apps-script.gs`** — Google Apps Script (لا يحتاج حسابًا مدفوعًا):
  1. https://script.google.com ← مشروع جديد ← الصق الكود.
  2. ⚙ Project Settings ← Script properties ← أضف:
     - `TELEGRAM_TOKEN` = رمز البوت
     - `RELAY_KEY` = مفتاح سري من اختيارك
  3. Deploy ← New deployment ← Web app ← Execute as: **Me** · Who has access: **Anyone**
  4. انسخ رابط `/exec`.
- **`worker.js`** — Cloudflare Worker (أسرع وأدق في CORS):
  1. Workers & Pages ← Create ← Worker ← الصق الكود.
  2. Settings ← Variables: `TELEGRAM_TOKEN` (Secret) و`RELAY_KEY`.
  3. Deploy ← انسخ رابط `*.workers.dev`.

## ٤) اربطها في المنصة

**سجل تلقرام ← ربط بوت تلقرام** (حساب المدير):

1. اختر الوضع.
2. الصق الرابط والمفتاح (أو الرمز والمعرّف في الوضع المباشر).
3. اضغط **«إرسال رسالة تجريبية»** — إذا وصلت للمجموعة فالإرسال يعمل مع كل تنبيهات المنصة.

## ٥) بوت واحد أم بوت لكل مدرسة؟

| النموذج | البنية | الملاحظات |
|---|---|---|
| **بوت واحد للمنصة** | بوت واحد + **مجموعة لكل مدرسة** | الأبسط والأقل صيانة — وهذا المُنفَّذ افتراضيًا |
| **بوت مستقل لكل مدرسة** | لكل مدرسة **رمز ومجموعة** مستقلان | هوية وتحكّم كاملين — شغّل «إعداد مستقل لكل مدرسة» في اللوحة |

للتفعيل: في لوحة الربط شغّل **«إعداد مستقل لكل مدرسة»** ثم أدخل لكل مدرسة معرّف مجموعتها
ورمز بوتها (اترك الرمز فارغًا لتستخدم بوت المنصة مع مجموعة المدرسة).

## ملاحظات مهمة

- الرسائل تصل للجميع في المجموعة؛ للإرسال الفردي يحتاج كل مستخدم أن يبدأ محادثة مع البوت.
- إذا ظهر خطأ CORS في الوسيط، تحقّق من وصول الرسالة للمجموعة؛ استخدم Cloudflare Worker للحسم.
- في الإنتاج (خادم + قاعدة بيانات) ينتقل الرمز إلى الخادم ويُشفَّر، ويصبح الربط لكل مدرسة تلقائيًا.
