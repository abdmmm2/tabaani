# استعادة كلمة المرور بالبريد — خطة التنفيذ
**النسخة:** v1 · **التاريخ:** 2026-10-17 · **الحالة:** جاهزة للتنفيذ

## الهدف
أي مستخدم (مدير · وكيل · إداري · معلم · طالب · مختص · محاسب · دعم) ينسى كلمة مروره ويستعيدها **بنفسه** عبر بريده المسجّل — بلا تدخّل المشرف العام وبلا جهاز معيّن.

## تجربة المستخدم (٥ خطوات · ~٩٠ ثانية)
1. شاشة الدخول ← «نسيت كلمة المرور؟»
2. يكتب **اسم المستخدم أو البريد** ← «أرسل رمز التحقق»
3. يوصله **كود ٦ أرقام** على بريده (صالح ١٥ دقيقة)
4. يكتب **الكود + كلمة المرور الجديدة** (مرتين)
5. يدخل مباشرة بكلمة المرور الجديدة ✓

## قواعد الأمان
- كود ٦ أرقام عشوائي، يُخزَّن **مشفَّرًا** (hash) في الخادم — لا يُحفظ كنص.
- صلاحية ١٥ دقيقة · **٣ محاولات** ثم يُلغى الكود.
- **حد إرسال**: ٣ طلبات/ساعة لنفس الحساب (منع الإزعاج والاستهلاك).
- الرد **دائمًا عام**: «إن كان الحساب موجودًا فقد أُرسل الرمز» — لا نكشف من له حساب.
- كلمة المرور الجديدة تُخزَّن **PBKDF2 (100k)** مثل بقية الحسابات.
- بعد النجاح: **إبطال كل الرموز (tokens)** والجلسات السابقة.
- كل عملية تُسجّل في سجل التدقيق (audit) بلا كشف الكود.

## ما سيُبنى تقنيًا
### الخادم (`cloud/worker.js`)
- `POST /api/auth/forgot` ← `{ ident }` ← إن وُجد المستخدم وله بريد: توليد كود + إرسال بريد + رد عام.
- `POST /api/auth/reset` ← `{ ident, code, password }` ← تحقق + تحديث + إبطال الرموز.
- جدول `reset_codes` (user_id · code_hash · expires_at · tries · created_at).
- استخدام `sendMail` الموجود (mail:true ✓) + قالب بريد عربي مختصر.

### التطبيق (`app/`)
- `App.forgot()`: عند وجود مزامنة مضبوطة ← المسار السحابي؛ وإلا يبقى المسار المحلي (أجهزة بلا سحابة).
- شاشة خطوتين: إدخال الهوية ← إدخال الكود + كلمة المرور الجديدة (مع «إعادة إرسال» وعدّاد).
- رسائل خطأ مفهومة: كود منتهٍ · كود خاطئ · محاولات كثيرة · بريد غير مسجّل (بنفس الرد العام).

### الفحص
- `tools/check-cloud.js`: مسارات جديدة + رفض الكود الخاطئ والمنتهي + منع كشف الحساب.
- تجربة كاملة: حساب تجريبي ← استعادة ← دخول بكلمة المرور الجديدة ✓.

## المطلوب من المالك
1. **توكن Cloudflare** جديد (٤ ضغطات) لنشر الخادم — يُحذف بعد النشر ✓.
2. بريد تجريبي للتأكد من وصول الكود ✓.
