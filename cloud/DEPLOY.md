# نشر تابعني على Cloudflare — دليل التنفيذ (١٠ دقائق · بلا بطاقة)

> الهدف: يطلع لك **رابط خادم** مثل `https://tabaani.xxxx.workers.dev` — بعده التسجيل العام والمزامنة تعمل من أول ضغطة.
> اختر **مسارًا واحدًا**: (أ) أمر واحد — الأسهل · (ب) لوحة Cloudflare بالمتصفح بلا أوامر.
> التكلفة داخل المجاني: ٠ ر.س (١٠٠ ألف طلب/يوم · ٥ جيجا · ٥ مليون قراءة/يوم · ١٠٠ ألف كتابة/يوم).

---

## المسار (٠) — «أعطني توكن وأنشر أنا عنك» (أسرع لك)

لو ما تبي تثبّت شي ولا تكتب أوامر: أنشئ **توكن Cloudflare** وأرسله، وأنا أنشر كل شيء من جهتي.

1. سجّل مجانًا: <https://dash.cloudflare.com/sign-up> (بريد + كلمة مرور، لا بطاقة).
2. **أنشئ التوكن:** <https://dash.cloudflare.com/profile/api-tokens> ← **Create Token** ← اختر قالب
   **«Edit Cloudflare Workers»** ← **Use template**.
   - ⚠️ **سطر مهم:** القالب **لا يشمل D1** — اضغط **+ Add more** ← **Account → D1 → Edit** قبل المتابعة.
   - **Account Resources:** Include → حسابك · **Zone Resources:** Include → Specific zone → نطاقك (أو احذف سطر Zone إن لم يكن عندك نطاق).
   - Continue ← **Create Token** ← انسخه (يظهر مرة واحدة).
   - *لو ما قدرت تضيف D1:* أنشئ القاعدة من اللوحة (D1 ← Create database ← الاسم tabaani ← Console ← الصق schema.sql)
     وانسخ **database_id** من صفحة القاعدة، ثم نفّذ: `D1_ID=<المعرّف> CF_API_TOKEN=... bash cloud/deploy-token.sh`
   *(قالب واحد يكفي: يمنح Workers + D1 — ولا يمنح الفواتير ولا أي شيء آخر.)*
3. أرسل التوكن، وأنشر أنا: قاعدة D1 · الجداول · الأسرار · الخادم · فحص الحماية · وإنشاء حساب المشرف العام.
4. **مهم:** بعد أن أخبرك أن النشر تمّ، اضغط **Delete** على التوكن من نفس الصفحة. (التوكن لا يُكتب في أي ملف عندي، ويُستخدم للتنفيذ فقط.)

وللتنفيذ من جهازك بالتوكن (بلا متصفح):
```bash
CF_API_TOKEN=xxxxx MAIL_ENDPOINT=https://... TG_TOKEN=... bash cloud/deploy-token.sh
```

## المسار (أ) — أمر واحد (مُفضَّل)

**ما تحتاجه:** جهاز فيه **Node.js** (نزّله من <https://nodejs.org> ثم أغلق الطرفية وافتحها من جديد) + حساب Cloudflare.

```bash
cd cloud
bash deploy.sh
```

**ما سيحدث، خطوة بخطوة:**

| الخطوة | ما تراه | ما تفعله |
|---|---|---|
| ١ | «فحص الكود محليًا» | لا شيء — ٤٠ فحصًا تمرّ تلقائيًا |
| ٢ | **يفتح المتصفح** على Cloudflare | سجّل دخولك (أو أنشئ حسابًا: بريد + كلمة مرور، **بلا بطاقة**) ثم ارجع للطرفية واضغط Enter |
| ٣ | «إنشاء قاعدة البيانات D1» | لا شيء — يُنشئ `tabaani` ويكتب معرّفها في `wrangler.toml` تلقائيًا |
| ٤ | تنفيذ الجداول | لا شيء — ٨ جداول و٩ فهارس |
| ٥ | الأسرار | يضبط `TOKEN_SECRET` عشوائيًا · ويسألك (Enter لتخطي): **MAIL_ENDPOINT** = رابط Apps Script المنشور (لإرسال أكواد التفعيل وبيانات الدخول) · **TG_TOKEN** = توكن بوت تلقرام |
| ٦ | «النشر» | انتظر ~٣٠ ثانية — يظهر **رابطك** |
| ٧ | «فحص صحة الخادم» | يطبع نتيجة `/api/health` ويحفظ الرابط في `cloud/.worker-url` |

**بعدها (مرتان فقط):**
1. **أنشئ حساب المشرف العام على الخادم** (يُطبع الأمر في نهاية السكربت):
```bash
curl -X POST "$(cat cloud/.worker-url)/api/seed?key=<SEED_KEY>" \
  -H 'Content-Type: application/json' -d '{"username":"admin","name":"المشرف العام"}'
```
> إن نسيت `SEED_KEY`: `npx wrangler secret put SEED_KEY` واضبطه من جديد.

2. **اربط المنصة بالمزامنة:** افتح المنصة ← **المزامنة السحابية** ← ضع الرابط + اسم المستخدم وكلمة المرور (حساب مدير المدرسة أو المشرف) ← «أقرن الآن».

**وتأكّد أن كل شيء محمي:**
```bash
node tools/check-deploy.js $(cat cloud/.worker-url)
```
يفحص: الخادم يستجيب · CORS · رفض الدخول الخاطئ ٤٠١ · حماية المسارات بلا رمز جلسة · رفض التسجيل الفارغ.

## المسار (ب) — لوحة Cloudflare بالمتصفح (بلا أوامر ولا Node)

مناسب لو ما تبي تثبّت شي على الجهاز. النتيجة نفسها، بس خطوات يدوية أكثر.

1. **حساب:** <https://dash.cloudflare.com/sign-up> (بريد + كلمة مرور — لا بطاقة).
2. **قاعدة البيانات:** من القائمة ← **Workers & Pages** ← **D1** ← **Create database** ← الاسم `tabaani` ← Create.
   - افتح القاعدة ← تبويب **Console** ← الصق **كامل** ملف `cloud/schema.sql` ← Run. (٨ جداول — لو ظهر جدول موجود تجاهله وأكمل.)
3. **الخادم:** **Workers & Pages** ← **Create** ← **Worker** ← الاسم `tabaani` ← **Deploy** (نسخة فارغة).
   - اضغط **Edit code** ← امسح كل شيء ← الصق **كامل** ملف `cloud/worker.js` ← **Deploy**.
   - ⚠️ مهم: ملف `worker.js` يستورد `./lib.js` — لذلك:
     - إمّا تلصق `lib.js` بعد `worker.js` بنفس المحرّر (Cloudflare يدعم ملفات متعددة عبر **Quick edit** ← إضافة ملف `lib.js`).
     - أو الأسهل: استخدم المسار (أ) الذي يرفع المجلد كما هو.
   - **الربط بقاعدة البيانات:** Settings ← **Bindings** (أو Variables) ← **Add** ← نوع **D1** ← Variable name: `DB` ← اختر قاعدة `tabaani` ← Save ← Deploy.
   - **الأسرار:** Settings ← Variables & Secrets ← Add: `TOKEN_SECRET` (نص عشوائي طويل) · `MAIL_ENDPOINT` · `TG_TOKEN` · `SEED_KEY`.
   - **رابط الخادم:** من صفحة الـWorker — مثل `https://tabaani.<حسابك>.workers.dev`.
4. **التهيئة والحساب:** في المتصفح: `https://<رابطك>/api/seed?key=<SEED_KEY>` بطلب POST (أو استخدم سطر curl في المسار أ).
5. **صفحة التسجيل:** افتح `https://abdmmm2.github.io/tabaani/site/register.html` ← في أعلى الصفحة ضع **رابط الخادم** واضغط «حفظ ومتابعة» (يُحفظ في متصفحك مرة واحدة).

## الاختبار السريع (دقيقتان) — بعد النشر

1. افتح `https://<رابطك>/api/health` → يجب أن يظهر `{"ok":true,...}` (و`mail:true` و`telegram:true` إن ضبطتهما).
2. افتح صفحة التسجيل ← املأ بيانات **مدرستك الحقيقية** (أو تجربة باسم «مدرسة تجربة») ← يجب أن يصلك **كود ٦ أرقام** على البريد.
3. أدخل الكود ← تظهر لك صفحة السداد ← يصير الطلب «موثَّق» وجاهزًا للاعتماد.
4. من المنصة (حساب المشرف) ← **اعتماد الطلبات**: اعتمد الطلب → تُنشأ المدرسة وحساب المدير وتُرسل بيانات الدخول بالبريد.
5. المنصة ← **المزامنة السحابية** ← «أقرن» ← «ارفع نسختي» ← افتح المنصة من جهاز آخر ← «نزّل نسخة الخادم» → **تظهر نفس البيانات وكشوف الدرجات** ✓

## جدول الأخطاء الشائعة

| ما يظهر | السبب | الحل |
|---|---|---|
| `database_id = "ضع-معرّف-القاعدة-هنا"` | لم يُنشأ D1 أو لم يُحدَّث الملف | `npx wrangler d1 create tabaani` ثم الصق المعرّف في `wrangler.toml` |
| `Binding DB not found` / خطأ D1 | الربط مفقود | أضف Binding من نوع **D1** باسم **DB** |
| `MAIL_ENDPOINT غير مضبوط` في الرد | لم يُضبط سرّ البريد | اضبطه (نفس رابط Apps Script المستخدم في النسخ الاحتياطي) |
| كود التفعيل لا يصل | البريد/Apps Script أو أنه في السبام | افحص السبام · تأكد أن Apps Script منشور «تطبيق ويب — أي شخص» · راجع `outbox` |
| `HTTP 401` في المنصة عند الإقران | اسم المستخدم/كلمة المرور غير موجودين على الخادم | أنشئ الحساب بـ`/api/seed` أو اعتمد طلب تسجيل |
| الصفحة العامة «تعذّر الاتصال» | رابط الخادم غير مضبوط في الصفحة | اضبطه من الخانة أعلى الصفحة (أو أضف `?api=https://...`) |
| المزامنة «تعارض: نسخة الخادم أحدث» | جهاز آخر رفع بعدك | اختر «نزّل نسخة الخادم» أو «ادمج وأعد الرفع» |

## ملاحظات أمنية (ما صار محميًا فعلًا)
- كلمات المرور على الخادم **مجزَّأة PBKDF2** (١٠٠ ألف دورة) — لا تُخزَّن صريحة.
- كل مسار محمي يتحقق من **رمز جلسة موقَّع** — ولا يُبنى العزل على إخفاء الأزرار.
- **البحث محصور على الخادم**: المشرف العام الكل · المدير مدرسته · **المعلم فصوله فقط**.
- **لا كتابة فوق نسخة أحدث** (تعارض ٤٠٨… بل ٤٠٩) — ولا فقدان بيانات.
- كل إرسال (بريد/تلقرام) يُسجَّل في «outbox» بنتيجته الصريحة — ولا نجاح كاذب.
