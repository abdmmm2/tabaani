# نشر تابعني **بلا توكن** — من لوحة Cloudflare بالمتصفح (١٢ دقيقة)

> هذه الطريقة لا تحتاج توكن ولا Node.js. تُلصق **مِلَف واحد** (`cloud/worker-single.js`) ويكون الخادم شغّالًا.
> ما تحتاجه: كمبيوتر (أسهل) أو جوال + بريد لإنشاء حساب Cloudflare المجاني (بلا بطاقة).

---

## ١) أنشئ حسابك (مرة واحدة)
<https://dash.cloudflare.com/sign-up> → بريد + كلمة مرور → تأكيد البريد.

## ٢) أنشئ قاعدة البيانات D1
1. من القائمة اليسرى: **Workers & Pages** ← تبويب **D1** ← **Create database**.
2. الاسم: **`tabaani`** ← **Create**.
3. **لا تفتح Console ولا تلصق شيئًا** — الخادم ينشئ الجداول بنفسه عند أول اتصال ✓ (ميزة self-migrate).
   *(وإن أردت التحقق: افتح `https://<رابطك>/api/init` وسترى «الجداول جاهزة».)*

## ٣) أنشئ الخادم والصق الملف الواحد
1. **Workers & Pages** ← **Create** ← **Worker** ← الاسم: `tabaani` ← **Deploy**.
2. اضغط **Edit code** (أو «</> Edit») ← امسح كل الموجود كاملًا.
3. افتح ملف **`cloud/worker-single.js`** ← حدّد الكل ← انسخ ← **الصقه** في المحرّر.
4. **Deploy** (أو Save and deploy).

## ٤) اربط قاعدة البيانات والخادم
في صفحة الخادم: **Settings** ← **Bindings** (أو Variables) ← **Add binding**:
| النوع | الاسم (Variable name) | القيمة |
|---|---|---|
| **D1 Database** | **`DB`** | `tabaani` |

← **Save** ← ثم **Deploy** مرة أخرى.

## ٥) الأسرار (Settings ← Variables and Secrets ← Add)
| الاسم | القيمة |
|---|---|
| **`TOKEN_SECRET`** | نص طويل عشوائي — مثال: انسخ هذا وغيّر بعض الأحرف: `t7Kq2mZ9pL4xV8nR3sB6yD1wE5uH0aG` |
| **`MAIL_ENDPOINT`** | رابط Apps Script المنشور عندك (الذي تُرسل منه الإيميلات) |
| **`TG_TOKEN`** | توكن بوت تلقرام: `8945311749:…` (نفس البوت @Tabaani_bot) |
| **`SEED_KEY`** | أي نص تختاره (مثلًا: `seed-1447`) |

بعدها اضغط **Deploy**. *(النوع: اجعلها Secrets إن أعطاك الخيار.)*

## ٦) فعّل الخادم وأنشئ حساب المشرف العام
1. افتح في المتصفح: `https://tabaani.<حسابك>.workers.dev/api/health` → يجب أن يظهر `{"ok":true,...}`.
2. أنشئ حساب المشرف العام: افتح الرابط التالي (POST):
```
https://tabaani.<حسابك>.workers.dev/api/seed?key=seed-1447
```
> إن رفض المتصفح طلب GET، استخدم أداة مثل «Postman» أو اطلب مني الأمر الجاهز على جهاز فيه Node.

## ٧) اربط المنصة بالمزامنة
1. افتح المنصة ← **☁️ المزامنة السحابية**.
2. **رابط الخادم:** `https://tabaani.<حسابك>.workers.dev`
3. **اسم المستخدم وكلمة المرور:** بيانات حسابك على الخادم (المشرف العام أو مدير المدرسة).
4. **«أقرن الآن»** ← ثم **«⬆️ ارفع نسختي إلى السحابة»**.

## ٨) صفحة التسجيل العامة (لعملائك)
افتح: <https://abdmmm2.github.io/tabaani/site/register.html> ← في أعلى الصفحة ضع **رابط خادمك** ← «حفظ ومتابعة».
⇒ بعدها أي عميل يسجّل مدرسته بنفسه وتصله بيانات الدخول بالبريد.

## جدول المشاكل الشائعة
| ما يظهر | السبب | الحل |
|---|---|---|
| `DB` غير معرّف / خطأ من قاعدة البيانات | لم يُضَف الـBinding | أعد الخطوة ٤ وتأكد الاسم **DB** بالضبط |
| `MAIL_ENDPOINT غير مضبوط` في الرد | لم يُضبط سرّ البريد | أعد الخطوة ٥ (استخدم نفس رابط Apps Script) |
| كود التفعيل لا يصل بالبريد | Apps Script غير منشور «أي شخص» | انشره كـ«تطبيق ويب — تنفيذ باسمي — أي شخص» |
| زر «Create Token» معطّل ويطلب **Zone Resource** | قالب التوكن يطلب نطاقًا | تجاهل التوكن واستخدم هذه الطريقة (بلا توكن) |
| المزامنة: «تعارض نسخة أحدث» | جهاز آخر رفع بعدك | اختر «نزّل نسخة الخادم» أو «ادمج وأعد الرفع» |
