# المرحلة الثانية — تابعني على Cloudflare (مجاني · بلا بطاقة)

> **للتنفيذ الآن:** اتبع `cloud/DEPLOY.md` (مسار الأوامر أو مسار اللوحة) — أو ببساطة: `bash cloud/deploy.sh`

هذا المجلد فيه **الكود الكامل** للمرحلة الثانية: خادم حقيقي + قاعدة بيانات + صفحة تسجيل عامة
يدخل عليها العميل بنفسه ويستلم كود التفعيل على بريده، ثم تُرسل بيانات الدخول لمدير المدرسة.

| الملف | الوظيفة |
|---|---|
| `worker.js` | الخادم: التسجيل · كود التفعيل · الدخول الحقيقي (PBKDF2) · الإقرارات · المزامنة · **البحث المحصور بالصلاحية** · اعتماد الطلبات |
| `lib.js` | منطق مشترك (تحقق المدخلات · التجزئة · الرموز · الأكواد · حصر البحث) — يعمل في Worker وفي Node للفحوص |
| `schema.sql` | جداول D1: الطلبات · أكواد التفعيل · المدارس · المستخدمون · الإقرارات · البيانات · الإرسال · التدقيق |
| `public/index.html` | صفحة التسجيل العامة (عربي RTL): بيانات المدرسة → كود التفعيل → السداد → التهيئة |
| `wrangler.toml` | إعداد النشر وربط D1 |

فحوص المنطق محليًا (بلا شبكة وبلا حساب):
```bash
node tools/check-cloud.js      # ٣٨ فحصًا
```

## النشر في ١٠ دقائق (بلا بطاقة بنكية)

1. أنشئ حسابًا مجانيًا على <https://dash.cloudflare.com/sign-up> (بريد + كلمة مرور، لا بطاقة).
2. في جهازك:
```bash
cd cloud
npx wrangler login                       # يفتح المتصفح لتفويض حسابك
npx wrangler d1 create tabaani           # أنشئ القاعدة — انسخ database_id وضعه في wrangler.toml
npx wrangler d1 execute tabaani --file=schema.sql --remote   # اختياري: الخادم ينشئ الجداول تلقائيًا
npx wrangler secret put TOKEN_SECRET     # نص طويل عشوائي (سر توقيع الجلسات)
npx wrangler secret put MAIL_ENDPOINT    # رابط Apps Script المنشور (لإرسال الأكواد وبيانات الدخول)
npx wrangler secret put MAIL_KEY         # اختياري: مفتاح يقبله Apps Script
npx wrangler secret put TG_TOKEN         # اختياري: توكن بوت تلقرام
npx wrangler secret put SEED_KEY         # مفتاح لإنشاء حساب المشرف العام مرّة واحدة
npx wrangler deploy
```
3. بعد النشر يعطيك رابطًا مثل `https://tabaani.<حسابك>.workers.dev` — ضعه في `cloud/public/index.html` مكان `API`
   وفي المنصة (بيانات تاباني ← المزامنة السحابية) لاحقًا.
4. أنشئ حساب المشرف العام (مرة واحدة):
```bash
curl -X POST "https://tabaani.<حسابك>.workers.dev/api/seed?key=<SEED_KEY>" \
  -H "Content-Type: application/json" -d '{"username":"admin","name":"المشرف العام"}'
```
5. تأكّد أن كل شيء يعمل: `GET /api/health` → `{ ok: true, mail: true, telegram: true }`.

## ما الذي يحلّه هذا (وأهميته لمدرستك)
- **دخول حقيقي**: كلمات المرور تُخزَّن مجزَّأة PBKDF2 — لا تُخزَّن صريحة، ولا يستطيع أحد قراءتها من الجهاز.
- **عزل فعلي**: كل طلب يحمل رمز جلسة، والخادم يفلتر بالصلاحية (**لا يُبنى على إخفاء الأزرار**):
  المشرف العام يرى الكل · مدير المدرسة مدرسته فقط · **المعلم فصوله فقط ولا يرى أي مستخدم آخر**.
- **لا ضياع بيانات**: نسخة المدرسة على الخادم (إصدارات — ولا تُكتب فوق نسخة أحدث بلا مراجعة).
- **البوت العام للعميل**: التسجيل وكود التفعيل وبيانات الدخول تصير بلا تدخّلك.
- **التكلفة**: ٠ ر.س — 100 ألف طلب/يوم · 5 جيجا D1 · 5 مليون قراءة/يوم · 100 ألف كتابة/يوم.

## سقف الخطة المجانية (تقدير عملي)
| الاستخدام | السقف المجاني | يكفي لـ |
|---|---|---|
| طلبات الخادم | 100,000 / يوم | ~٢٠ مدرسة × ١٠٠٠ مستخدم |
| كتابات D1 | 100,000 / يوم | مزامنة كل تغيير صغير |
| قراءات D1 | 5,000,000 / يوم | بحث وتقارير كثيفة |
| حجم الدي | 5 جيجا | سنوات من البيانات لمدارس متوسطة |

عند تجاوز ذلك: D1 مدفوع 5$ ≈ 19 ر.س/شهر لكل مدرسة إضافية — أو R2 للتخزين الرخيص.
